# 有序 · 任务看板

Vue 3 + Vite 的纯前端任务看板。任务保存在当前浏览器的 localStorage，不需要后端、账号或付费服务。

## 运行

建议使用 Node.js 22.12 以上。当前验证环境为 Node.js 26.3.0 / npm 11.16.0。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建和预览：

```bash
npm run build
npm run preview
```

`dist/` 是静态构建目录，可交给支持静态站点的免费发布入口。源码以 `package-lock.json` 固定安装版本，`vite.config.js` 使用相对静态资源路径。

## 使用

- 点击“新建任务”，填写标题、描述、分类和状态；标题必填，描述可选。
- 使用卡片右上角图标编辑或删除；删除前需在应用弹窗确认。
- 拖动卡片到“待办 / 进行中 / 完成”切换状态；手机或键盘用户可使用卡片底部状态菜单。
- 左侧按工作、学习、生活、其他分类筛选，也可搜索标题或描述。
- 保存后刷新页面会恢复记录；同一浏览器的其他标签页更新时会同步。

数据只属于当前浏览器和站点地址。切换设备、浏览器、访问地址或清除站点数据不会继承旧记录。存储写入失败会明确提示；加载发现损坏数据时暂停修改，不自动覆盖原始记录。
